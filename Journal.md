# Journal
Phase 1
The swap method is useful in several sorthing methods. The selection sort swaps the next smallest value with the 
first value in an array.

Phase 2
The number of comparisons does not change for selection sort if the array is already sorted, because it doesn't 
include any check for early exit conditions and it must scan the entire array at least once to find the smallest 
value.

Phase 3
There is always a trade off. The faster sorting algorithms use more memory, and the slower algorithms use minimal
O(1) memory. The merge sort algorithm uses more ram for the extra arrays it creates for the sorting process.
